# Lia AI — Premium UI Starter

A mobile-first static interface based on the Lia AI concept, with a premium midnight / violet / cyan visual system.

## Files
- `index.html` — app screens and navigation
- `style.css` — responsive visual design
- `app.js` — local navigation, provider selection UI, and chat preview

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Important security note
This is a frontend preview, not a connected AI assistant yet. Do not paste real Gemini or Groq API keys into browser HTML/JavaScript. Browser files can be inspected. Before adding real keys, build a protected backend proxy and keep provider credentials on the server. The chat currently shows a preview notice rather than sending messages to an AI provider.
